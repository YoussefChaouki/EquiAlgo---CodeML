**IVADO** - EquiAlgo (**IVADO** - EquiAlgo) Description du challenge Concevez un modèle d’octroi de bourses étudiantes qui tient compte des biais historiques et de l’équité entre régions.

Qu'allez-vous accomplir? Analysez les décisions historiques, entraînez votre modèle et produisez les décisions pour les 4 **000** candidats d’évaluation. Expliquez votre approche, ses performances et ses limites d’équité.

Critère pour le jugement Le jury **IVADO** évalue votre solution selon les consignes. HxBuddy affiche uniquement un indicateur F1 macro et accuracy, comparé au mérite réel ; il ne reproduit pas la notation **IVADO** sur 35 points.

Accuracy F1 macro Score indicatif (F1)

Comment soumettre votre modèle? Notebook, prédictions, documentation et présentation demandés dans les consignes.

Sur Devpost, sélectionnez exactement un prix correspondant à ce défi, même si le champ est facultatif. Un projet = un défi = un prix. Pour plusieurs défis, créez plusieurs projets. Utilisez le même nom d’équipe et les mêmes membres que sur HxBuddy.

Téléverser un fichier .csv. Ce fichier doit contenir au minimum toutes les données qui n'ont pas de label initialement qu'on vous a fournis dans le jeu de données. Nous devons avoir votre colonne de `label` ainsi que `id` dans le fichier pour pouvoir évaluer votre modèle sinon la soumission ne fonctionera pas.

Vous avez jusqu'à 20 soumissions par heure par équipe pour tous les défis confondus.

**CSV** requis : id_candidat,decision_octroi ; une ligne pour chacun des 4 **000** candidats, valeurs 0 ou 1. Le score est un indicateur, pas la note finale du jury.

Consignes et données - **IVADO** - EquiAlgo Le **ZIP** comprend les consignes FR/EN, le notebook de départ, 10 **000** demandes historiques avec labels et 4 **000** candidats sans réponses. Les corrigés du jury restent privés.
